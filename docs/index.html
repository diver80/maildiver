Native Email, Calendar & Contacts — with Flexible Local & Cloud AI

PostDive is a fast, standalone desktop & mobile suite written in Go and mygo. Zero Electron bloat, instant SQLite search, privacy-first security, 1-click Thunderbird import, and your choice of local Ollama or cloud AI (Claude, Gemini, OpenAI).

Built for speed, privacy, and real daily work

Everything lives in one native binary: direct IMAP/SMTP engine, local SQLite cache, calendar, contacts, and an opt-in AI copilot you stay in control of.

✦

Flexible AI & Built-in MCP Server

Run completely locally via MTPLX (Inkling 2 Mini on Apple Silicon), Ollama, llama.cpp or llamafile — or connect Claude, Gemini, OpenAI, and CLI agents with Personal AI Instructions. Plus a built-in local stdio MCP server (postdive --mcp) for Claude Code, Cursor, Antigravity & Claude Desktop (read-only by default, never sends or deletes). Local filter rules run at 0 tokens.

MCP Server MTPLX / Ollama Claude / Gemini 0-Token Rules
⚡

Native Performance & Compact Sidebar

Compiled Go backend + GPU-accelerated mygo UI in a single process. Instant local SQLite FTS5 search, Focus (Unread & ★), smart compact folder sidebar (shows INBOX & active rule targets up front and collapses less-used folders into “More folders” on phone & desktop), real-time IMAP IDLE, keyboard shortcuts (j/k/r/e/v/c/s), and detached compose & event windows.

Go + mygo GPU SQLite FTS5 Compact Folders No Electron
🔒

Security: S/MIME & Native OpenPGP

Full S/MIME (.p12 import) AND native OpenPGP (PGP/MIME & Inline PGP without external gpg, WKD/VKS lookup, OS Keychain storage, fail-closed encryption), remote images blocked by default with per-sender allowlist, strict HTML sanitizer, pixel-bomb & SSRF guards, TLS/STARTTLS-only transport, and risky attachment protection.

S/MIME OpenPGP OS Keychain Tracker Blocking
📅

Complete Suite: Mail, Calendar & Contacts

Multi-account IMAP/SMTP (incl. Gmail & Microsoft 365 XOAUTH2) with desktop HTML WYSIWYG compose (inline pasted images, editable tables, drag & drop attachments), offline outbox, inline .ics RSVP, Month/Week/Agenda calendar with Google & CalDAV sync, and local + Google + CardDAV Contacts.

XOAUTH2 CalDAV / CardDAV Calendar & .ics Contacts

Effortless Setup, Thunderbird Import & LAN QR

Switch in minutes: read-only Thunderbird importer brings over accounts, signatures, calendars, contacts & filter rules automatically, plus one-shot AES-256-GCM LAN QR-code transfer to set up another desktop or Android phone in seconds.

Thunderbird Import LAN QR Sync Rule Editor

Cross-Platform: Desktop & Android

Native builds for macOS (Apple Silicon & Intel), Linux (x64 & arm64 with live Omarchy theme sync), Windows (x64 & arm64), and Android via mygo — sharing one single codebase and 22 built-in themes.

Install or Build from Source

Grab a prebuilt binary from GitHub Releases or compile directly with Go.

Homebrew & Quick Build

# macOS (Universal App + CLI)
brew install --cask diver80/tap/postdive

# Linux / CLI
brew install diver80/tap/postdive

# Connect Claude Code / Cursor / Antigravity via built-in MCP
claude mcp add postdive -- postdive --mcp

# Or build from source
git clone https://github.com/diver80/postdive.git
cd postdive && ./build.sh && ./install.sh

Android builds use ./build.sh --android (requires Android NDK). Prebuilt macOS Universal .dmg and desktop binaries are attached to every GitHub Release.
