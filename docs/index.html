Native Email, Calendar & Contacts — with Flexible Local & Cloud AI

MailDiver is a fast, standalone desktop & mobile suite written in Go and mygo. Zero Electron bloat, instant SQLite search, privacy-first security, 1-click Thunderbird import, and your choice of local Ollama or cloud AI (Claude, Gemini, OpenAI).

Built for speed, privacy, and real daily work

Everything lives in one native binary: direct IMAP/SMTP engine, local SQLite cache, calendar, contacts, and an opt-in AI copilot you stay in control of.

✦

Flexible AI — Local & Cloud

Run completely offline with Ollama (e.g. Inkling 2 Mini via ollama run inkling-2-mini on 32GB+ Apple Silicon), llama.cpp or llamafile, or connect Anthropic Claude, Google Gemini, OpenAI, or CLI agents (claude-cli, gemini-cli, opencode-cli). Local filter rules use zero tokens, and the AI copilot only proposes actions — nothing executes without your click.

Ollama / Inkling 2 Claude / Gemini CLI Agents 0-Token Rules

Native Performance

Compiled Go backend + GPU-accelerated mygo UI in a single process. Instant local SQLite FTS5 full-text search, Focus view keeping Unread & ★ Starred mails pinned, persistent folder trees, real-time IMAP IDLE sync, keyboard-first navigation (j/k/r/e/v/c/s), and detached compose & event windows.

Security & S/MIME / PGP

Full S/MIME support (.p12 import with OS Keychain keys, signature verification, decryption, signing & AES-256 encryption), remote images blocked by default with per-sender allowlist, strict HTML sanitizer, pixel-bomb & SSRF guards, TLS/STARTTLS-only transport, and risky attachment protection.

Complete Suite: Mail, Calendar & Contacts

Multi-account IMAP/SMTP (incl. Gmail & Microsoft 365 XOAUTH2) with desktop HTML WYSIWYG compose (inline pasted images, editable tables, drag & drop attachments), offline outbox, inline .ics RSVP, Month/Week/Agenda calendar with Google & CalDAV sync, and local + Google + CardDAV Contacts.

Install or Build from Source

Grab a prebuilt binary from GitHub Releases or compile directly with Go.

Homebrew & Quick Build

# macOS (Universal App + CLI)
brew install --cask diver80/tap/maildiver

# Linux / CLI
brew install diver80/tap/maildiver

# Or build from source
git clone https://github.com/diver80/maildiver.git
cd maildiver && ./build.sh && ./install.sh

Android builds use ./build.sh --android (requires Android NDK). Prebuilt macOS Universal .dmg and desktop binaries are attached to every GitHub Release.
