Native Email, Calendar & Contacts — with Flexible Local & Cloud AI

PostDive is a fast, standalone desktop & mobile suite written in Go and mygo — featuring Diver themes, a calm inbox, Cron-style calendar, inline Quick-Reply, consistent right-side AI dock, and 1-click local MCP setup with zero Electron bloat.

Built for speed, privacy, and real daily work

Everything lives in one native binary: direct IMAP/SMTP engine, local SQLite cache, calendar, contacts, and an opt-in AI copilot you stay in control of.

✦

Right-Side AI Dock & 1-Click MCP Server

Consistent right-side AI dock in both the main workspace and Compose/Reply windows, plus inline Quick-Reply AI chips. Run 100% locally via MTPLX, Ollama, llama.cpp or llamafile — or connect Claude, Gemini, OpenAI, and sandboxed CLI agents (claude-cli, agy, opencode-cli). Connect Claude Desktop, Cursor, Antigravity or Claude Code via postdive --mcp with 1-click client setup. Local filter rules run at 0 tokens.

Calm Mail Redesign, Snooze & Subscriptions

Focus (Unread & ★) inbox with sender avatars, All/Unread/★/Attachments filter pills, Snooze presets with automatic wake-up, 0-token Waiting-for-Reply reminders, Subscriptions cleanup with One-Click unsubscribe, inline Quick-Reply with Undo-Send, SQLite FTS5 search, smart compact folder sidebar, IMAP IDLE, and keyboard shortcuts (j/k/r/e/v/c/s).

Go + mygo GPU SQLite FTS5 Snooze & Cleanup No Electron
🔒

Security: S/MIME, OpenPGP & Privacy Guards

Full S/MIME (.p12 import) AND native OpenPGP (PGP/MIME & Inline PGP without external gpg, WKD/VKS lookup, OS Keychain storage, fail-closed encryption). Encrypted and decrypted mails are strictly blocked from all AI backends. Remote images are blocked by default with a tracker-pixel counter pill, per-sender allowlist, strict HTML sanitizer, SSRF/pixel-bomb guards, and TLS/STARTTLS-only transport.

S/MIME OpenPGP Never Sent to AI Tracker Counter

Gmail & Microsoft 365 XOAUTH2) with desktop HTML WYSIWYG compose, offline outbox, Cron-style 24h Day/Week calendar grid, collapsible mini-month & multi-account sidebar, Live-Meeting toolbar pill with 1-click Join, inline .ics RSVP with Free/Busy conflict badge, Google Calendar & CalDAV sync, and unified Contacts.

Switch in minutes: read-only Thunderbird importer brings over accounts, signatures, calendars, contacts & filter rules automatically, plus one-shot AES-256-GCM LAN QR-code transfer in Settings → AI & Sync to set up another desktop or Android phone in seconds.

Install or Build from Source

Grab a prebuilt binary from GitHub Releases or compile directly with Go.

Homebrew & Quick Build

# macOS (Universal App + CLI)
brew install --cask diver80/tap/postdive

# Linux / CLI
brew install diver80/tap/postdive

# Connect Claude Code / Cursor / Antigravity via built-in MCP
claude mcp add postdive -- postdive --mcp

# Or build from source
git clone https://github.com/diver80/postdive.git
cd postdive && ./build.sh && ./install.sh

Android builds use ./build.sh --android (requires Android NDK). Prebuilt macOS Universal .dmg and desktop binaries are attached to every GitHub Release.
